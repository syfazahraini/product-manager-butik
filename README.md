# Product Manager - Butik Syfaaa

Aplikasi web manajemen katalog dan stok produk Butik Syfaaa.

## Fitur & Keamanan
- CRUD Produk (Create, Read, Update, Delete)
- Keamanan PDO Prepared Statement (Cegah SQL Injection)
- Escaping htmlspecialchars (Cegah XSS)
- CSRF Token & Pola PRG
- UI Responsif Flexbox (Warna Maroon)

## Cara Jalankan
1. Import `database/store_db.sql` di phpMyAdmin.
2. Buka `http://localhost/product-manager/public/index.php`.
